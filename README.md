# Telegram-бот «Комплексы упражнений»

Минимальная версия персонального Telegram-бота для выбора комплексов и прохождения курсов.

## Что умеет

- **Сегодня** — только активные комплексы на текущий день.
- **Мои курсы** — активные, на паузе, завершённые.
- **Библиотека** — постоянный список комплексов.
- **Добавить комплекс** — ссылка → название → автор → время дня → дни недели.
- Курс можно задать **по календарю** или **по количеству выполнений**.
- Отметки: **✓ Сделала** и **Пропустить сегодня**.
- Курс можно поставить на паузу, завершить и позже **начать снова**.
- Старая история повторных курсов сохраняется.

## Логика курсов

### По календарю
Например, 14 дней. Курс длится 14 календарных дней с даты старта, а комплекс показывается только в выбранные дни недели.

### По количеству выполнений
Например, 12 занятий по Вт/Чт/Сб. Курс завершится после 12 отметок «Сделала». Пропуск не уменьшает цель.

## Установка

Нужен Python 3.11+.

1. В Telegram открыть **@BotFather**, выполнить `/newbot` и получить токен.
2. Создать виртуальное окружение.
3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Скопировать `.env.example` в `.env` и вставить токен:

```env
BOT_TOKEN=1234567890:ваш_токен
DB_PATH=exercise_bot.db
```

5. Запустить:

```bash
python bot.py
```

6. Открыть своего бота и нажать `/start`.

## Данные

Все комплексы, курсы и отметки хранятся в `exercise_bot.db`. Для резервной копии достаточно копировать этот файл.

## Что сознательно не включено в первую версию

Категории, длительность видео, вес/сон/питание, Notion, автоматическое чтение YouTube и напоминания. Сначала проверяем сценарий: **Сегодня → видео → Сделала**.
